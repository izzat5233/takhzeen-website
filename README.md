# Takhzeen

## 🏢 About

- Takhzeen is a storage services company that offers temporary solutions and partial storage rentals.
- These services are primarily available through the company's website.
- This project is the frontend part of Takhzeen website. Built with React & Tailwind.

## 🌐 Language Support

The website supports both **Arabic** and **English** languages:
- 🇵🇸 Arabic (default) - Right-to-left (RTL) layout
- 🇬🇧 English - Left-to-right (LTR) layout

Users can switch between languages using the language switcher button in the navigation bar. The selected language preference is saved in the browser's local storage.
